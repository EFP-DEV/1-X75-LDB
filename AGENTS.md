# Communication preferences

Use plain, direct, neutral, serious language in all conversations and text written for the user. Do not use jokes, humor, puns, wordplay, sarcasm, quirky phrasing, or playful asides.

# Code testing

Never test code. Do not run automated tests, syntax checks, browser checks, or execute code to verify its behavior. Base code assessments on reading the source only.

# Image viewing

Do not view images. Image inspection takes too much time; rely on available text instead.

# Canonical source for lesson content

[referentiel.md](referentiel.md) contains the supplied summary of the official EFP référentiel and the course objectives. Treat it as the canonical source for the competencies and practical operations to cover in this module.

- Read it before creating or updating lessons, exercises, demonstrations, revision material or assessments.
- Align learning objectives and activities with its requirements. Ensure that the course as a whole covers all listed competencies; each lesson contributes according to its place in the progression.
- Include opportunities to perform the operations, verify their results and explain the choices made.
- Use [readme.md](readme.md) for the planned sequence of lessons and the module organisation.
- If a lesson or the planned sequence conflicts with the référentiel, use the référentiel to determine the required coverage and flag the discrepancy.
