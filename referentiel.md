Le module vise à apprendre à **concevoir, créer, exploiter et maintenir une base de données simple**, principalement relationnelle, et à s’y connecter de manière sécurisée dans le cadre d’une application web.

À l’issue du module, l’étudiant doit être capable de :

| Domaine | Apprentissages et compétences |
|---|---|
| **Comprendre les bases de données** | Comprendre le rôle d’un SGBD, distinguer les principales familles de bases de données, notamment relationnelles et NoSQL, et leurs usages. |
| **Organiser et modéliser les données** | Analyser un besoin, identifier les données et leurs relations, représenter une architecture simple et construire les modèles conceptuel et logique : MCD et MLD. |
| **Structurer une base relationnelle** | Définir les tables, les champs, les types de données, les clés et les contraintes. Normaliser les données pour limiter les redondances et les incohérences. |
| **Exploiter les données avec SQL** | Rechercher, filtrer, trier, ajouter, modifier et supprimer des données ; rapprocher plusieurs tables au moyen de jointures ; comprendre l’utilité des index. |
| **Utiliser les outils adaptés** | Prendre en main les outils de modélisation et d’administration, les serveurs locaux et les outils de connexion à une base de données. |
| **Installer et maintenir une base** | Installer et configurer un système de bases de données simple, créer une base, s’y connecter et réaliser les opérations courantes de maintenance. |
| **Gérer les accès et la sécurité** | Créer des comptes utilisateurs, attribuer les droits nécessaires et appliquer les bonnes pratiques de sécurité, y compris pour les connexions distantes. |
| **Sauvegarder et restaurer** | Effectuer des sauvegardes et restaurer les données afin de préserver leur disponibilité. |
| **Exploiter des fichiers de données** | Utiliser des fichiers plats (*flat-files*) et comprendre leur place dans le stockage et l’échange de données. |
| **Développer son autonomie** | Consulter la documentation technique, rechercher des solutions et suivre l’évolution des outils utilisés. |

Les compétences portent sur **la compréhension et la mise en pratique** : l’étudiant doit pouvoir réaliser les opérations, vérifier leurs résultats et expliquer ses choix.

# LDB : Langages de base de données

**X75 · Première année · 48 heures**

Ce cours vous apprend à **concevoir, créer, exploiter et maintenir une base de données simple**, puis à vous y connecter de manière sécurisée pour en utiliser les données dans une application web. Il porte principalement sur les bases de données relationnelles.

## Objectifs d’apprentissage

À l’issue du cours, vous serez capable de :

- **Comprendre les bases de données** : rôle d’un SGBD, principales familles de bases de données et différences entre les approches relationnelles et NoSQL.
- **Modéliser les données** : analyser un besoin, identifier les entités et leurs relations, construire les modèles conceptuel et logique : MCD et MLD.
- **Structurer une base relationnelle** : définir les tables, les champs, les types, les clés et les contraintes ; normaliser les données pour limiter les redondances et les incohérences.
- **Manipuler les données avec SQL** : rechercher, filtrer, trier, ajouter, modifier et supprimer des données ; effectuer des jointures et comprendre l’utilité des index.
- **Utiliser les outils adaptés** : outils de modélisation, d’administration et de connexion aux bases de données.
- **Installer et maintenir une base** : configurer un environnement local, créer une base, s’y connecter et effectuer les opérations courantes de maintenance.
- **Sécuriser les accès** : gérer les comptes utilisateurs et leurs permissions, appliquer les bonnes pratiques de sécurité et établir des connexions distantes.
- **Sauvegarder et restaurer les données**.
- **Exploiter des fichiers plats** pour stocker et échanger des données.
- **Travailler de manière autonome** : consulter la documentation technique, rechercher des solutions et suivre l’évolution des outils.

## Mise en pratique

Vous apprendrez à réaliser ces opérations, à vérifier leurs résultats et à expliquer vos choix. Les exercices porteront sur les données du projet commun, une **application centrée sur les collections**, déclinable en application de collections, réseau social ou boutique pour l’atelier ADB.

## Organisation

Le cours comprend **12 séances** :

- **10 séances d’apprentissage et de pratique** ;
- **1 séance de révision générale**, sans matière nouvelle ;
- **1 examen pratique individuel**.
