# Séance 1 — Corrigé formateur des treize questions

Ce corrigé reprend les treize questions du [support étudiant](../session_01.md#5-rechercher-dans-le-classement) et de la [préparation de séance](session_01.md#questions-de-la-séance), dans le même ordre : dix recherches d’informations et trois comptages. Les réponses sont établies à partir des descriptions textuelles de [exo/session_01.html](../exo/session_01.html) et de l’[inventaire du corpus](../asset/session_01/README.md). Les difficultés visuelles sont estimées à partir de ces descriptions.

Les groupes répondent d’abord à partir de leur classement. La démonstration et la pratique de Ctrl+F reprennent ensuite la même série : ouvrir le code source du plateau avec **Ctrl+U**, puis chercher le terme avec **Ctrl+F**. Lire le contexte de la correspondance et relever le numéro `data-id` du document. En classe, rapprocher la réponse de l’image et conserver les preuves dans `observations-classement.md`.

Les questions 1, 2, 5 et 12 utilisent « Quel document » sans annoncer sa catégorie. Faire expliciter les hypothèses de classement qu’une propriété suscite avant de chercher. Par exemple, la mention d’un compositeur peut orienter vers un disque, mais aussi vers un film ou un spectacle. Les attributs permettent de retrouver et de regrouper les documents selon différents critères.

## Repères pour la démonstration et la correction

Suivre le [déroulé de la démonstration](session_01.md#démonstration--rechercher-dans-le-code-source) : `1.99` pour la question 1, `Megadeth` pour distinguer occurrences et documents, puis `Couverture de livre` pour la question 3. Les groupes reprennent ensuite une recherche d’information, les trois comptages et un comptage trompeur.

Dans le code source du plateau, une recherche de `Megadeth` sans distinction de casse donne quatre occurrences pour deux documents, 06 et 16 : le nom est présent dans le chemin et dans la description de chaque image. `B12` permet de retrouver précisément le billet de la question 9. Pour les comptages, les expressions complètes évitent les correspondances avec `livret` ou avec `affiche` dans certains chemins de fichiers.

Une réponse de recherche identifie le document et la mention qui la justifie. Un comptage fournit le total et tous les numéros retenus. En cas d’écart, confronter les inventaires pour repérer les omissions, doublons ou différences de convention. Distinguer toujours le numéro de la question du numéro du document.
